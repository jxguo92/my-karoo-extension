# Concentric：同心双弧 Data Field 原型图描述

参考：[草图](sketch.png) · [同心仪表参考图](inspiration.jpg)。草图决定布局；参考图只提供同心仪表的整体感觉。

## 生成画面

生成一张 **480 px 宽、800 px 高的竖屏界面图**，展示完整 Karoo 屏幕，不画机身。最外侧有一圈边框，四角半径为 8 px。高度分为顶部约 81 px、中间约 638 px、底部约 81 px。顶部左侧固定显示骑行时间 `01:24:36`，右侧固定显示当前时间 `14:32`；中间是独占 5 行×2 列页面的 Data Field；底部留空。四套 dashboard 原型使用相同的屏幕比例和示例读数。

中间区域上方沿用草图的**两层同心、向下开口的宽弧**：外弧是 3 秒功率分区条，内弧是踏频分区条。两条弧各有独立的当前值标记，不能合成一个读数。弧内自上而下安排 `GEAR 6/13`、主要读数 `3s PWR 245 W`，以及 `SPD 28.6 km/h`。踏频在这套布局中由内弧和当前值标记表达，不另外显示踏频数字。中间区域的左上角放相对来风的小箭头 `W`，表示风来自骑手左前方；右上角放指北针小箭头 `N`，北指向画面右上方。

弧形表盘下方按草图排列两行辅助读数：

- 第一行从左到右：`DIST 42.7 km`、`HR 156 bpm`、`GRADE +4.8%`。
- 最下一行从左到右：`AVG SPD 27.4 km/h`、`AVG HR 148 bpm`、`AVG PWR 198 W`、`NP 214 W`。

短标签取代草图中的单字母代号。后拨档位 `6/13` 是序号，不显示飞轮齿数。让中央功率读数与两层弧成为视觉核心，同时确保底部四项读数在实际显示区域内可辨认；字号、材质、光效与装饰细节留给原型探索。

## 分区条语义

内侧踏频弧覆盖 51–110 rpm，每 5 rpm 一段，共 12 段；51–80 为白色，81–100 为绿色，101–110 为红色。超出范围时，当前值标记停在最近的端点。外侧功率弧从 0 到用户最高功率区的最大值，使用 Karoo 用户功率分区；各区在弧上等宽，区内按数值线性插值，颜色方向大体由绿、蓝、红到紫，具体色值暂不固定。两个当前标记分别指向 88 rpm 和 245 W。心率在此方案里只显示数字，不额外增加草图没有的心率弧。

这张图只展示一次骑行中的正常读数。后续原型可通过 JavaScript 改变数值和标记位置；缺失、断线等状态属于下一阶段。
