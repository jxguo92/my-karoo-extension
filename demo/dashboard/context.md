# 设计意图

汽车仪表盘风格的聚合型data field, 占据整张page - 5行2列


# sketch symbols

P: 3s功率
C: 踏频
H: 心率
S: 速度
W: 风向
Dr: 方向
G: 档位
D: 距离
ah: 平均心率
as: 平均速度
ap: 平均功率
np: 标准化功率
gr: 坡度
线段代表一个带分区的bar, 具体内容由距其最近的symbol决定


# 设计细节

踏平线段显示51-110, 超出范围按最值显示; 每5rpm一个分区, 总共12区; 51-80对应分区为白色, 81-100为绿色, 101-110为红色

心率线段显示0-最大心率; 采用系统提供的分区; 分区颜色具体数值待定，整体上绿->蓝->红->紫

功率线段显示0-最大区局.max; 采用系统提供的分区; 分区颜色具体数值待定，整体上绿->蓝->红->紫

线段分区长度和刻度方式参考`cycling-power-linear-scale-patterns.md`的"每个功率区等宽，区内线性插值"

分区方式和颜色参考`karoo-zone-colors-in-extensions.md`
