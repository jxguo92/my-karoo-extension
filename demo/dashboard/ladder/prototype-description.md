# Ladder：踏频灯珠、双竖条与速度圆表 Data Field 原型图描述

参考：[草图](sketch.png) · [汽车仪表盘参考图](inspiration.jpg)。草图决定指标位置；参考图提供两侧宽刻度带的轮廓与汽车仪表盘的整体感觉。

## 生成画面

生成一张 **480 px 宽、800 px 高的竖屏界面图**，展示完整 Karoo 屏幕，不画机身。最外侧有一圈边框，四角半径为 8 px。高度分为顶部约 81 px、中间约 638 px、底部约 81 px。顶部左侧固定显示骑行时间 `01:24:36`，右侧固定显示当前时间 `14:32`；中间是独占 5 行×2 列页面的 Data Field；底部留空。四套 dashboard 原型使用相同的屏幕比例和示例读数。

中间区域的顶端横排 **12 个彼此分开的竖向长方形灯珠**，组成踏频分区指示条。这一排借鉴仪表盘灯珠的排列方式，但使用竖向长方形而非圆点；从第一个灯珠连续点亮到当前踏频所在灯珠，其余保持较暗。示例 88 rpm 点亮第 1–8 个灯珠，**不显示踏频数字**。

灯珠下方保留草图的纵向结构：左侧是较宽的功率分区刻度带，右侧是较宽的心率分区刻度带。两条刻度带参照 `inspiration.jpg` 中央两侧的仪表形状，略向下张开，形成容纳中央圆表的空间；它们仍分别显示功率和心率，而非照片中的档位刻度。功率带附近显示 `3s PWR 245 W`，心率带附近显示 `HR 156 bpm`。两条刻度带的分区颜色始终可见，各有一条醒目的横向标记指向当前值。

两条宽刻度带之间加入一个 **3/4 圆的速度指示条**，范围为 0–60 km/h，不分区，圆弧缺口朝下。完整速度刻度保持可见，指针指向 28.6 km/h。`GEAR 6/13` 和更大的 `SPD 28.6 km/h` 都放在圆表内部，档位在上、速度在下；速度文字的最下沿与圆表下方缺口的切线齐平。档位是后拨序号，不显示飞轮齿数。

下方按草图继续排列读数：

- 中下部从左到右：`DIST 42.7 km`、`AVG HR 148 bpm`、`AVG SPD 27.4 km/h`。
- 最底部从左到右：相对来风小箭头 `W`、`AVG PWR 198 W`、`NP 214 W`、指北针小箭头 `N`。

`W` 表示风来自骑手左前方；`N` 指向画面右上方。两个箭头的位置遵循本张草图，放在 Data Field 下方两侧，与其他方案放在上方角落的布局不同。短标签取代草图中的单字母代号。让中央速度读数最醒目，同时保留档位、两侧宽刻度带和底部所有辅助指标；字号、材质、光效与装饰细节留给原型探索。

## 分区条语义

顶部 12 个踏频灯珠覆盖 51–110 rpm，每 5 rpm 一个灯珠；51–80 为白色，81–100 为绿色，101–110 为红色。当前值从左端累计点亮到所在灯珠，超出范围时按最近端点显示。左侧功率刻度带从 0 到用户最高功率区的最大值，右侧心率刻度带从 0 到用户最大心率，分别采用 Karoo 用户功率和心率分区；各区在刻度带上等长，区内按数值线性插值。功率、心率的颜色方向大体由绿、蓝、红到紫，具体色值暂不固定；横向标记分别指向 245 W 和 156 bpm。中央速度圆弧是单一的 0–60 km/h 连续刻度，不采用颜色分区，指针指向 28.6 km/h。

这张图只展示一次骑行中的正常读数。后续原型可通过 JavaScript 改变数值和标记位置；缺失、断线等状态属于下一阶段。
