# Tri：三表盘 Data Field 原型图描述

参考：[草图](sketch.png) · [三表汽车仪表盘参考图](inspiration.jpg) · [骑行码表参考图](inspiration2.jpeg)。草图决定布局；参考图只提供三个表盘并列时的整体感觉。

## 生成画面

生成一张 **480 px 宽、800 px 高的竖屏界面图**，展示完整 Karoo 屏幕，不画机身。最外侧有一圈边框，四角半径为 8 px。高度分为顶部约 81 px、中间约 638 px、底部约 81 px。顶部左侧固定显示骑行时间 `01:24:36`，右侧固定显示当前时间 `14:32`；中间是独占 5 行×2 列页面的 Data Field；底部留空。四套 dashboard 原型使用相同的屏幕比例和示例读数。

中间区域上半部沿用草图的**中央圆环与左右包围弧**：中央是一条较大的 3 秒功率开口圆环；踏频弧沿圆环左侧向外鼓起，心率弧沿右侧对称向外鼓起。左右弧不是两个独立的小圆表，也不与中央圆环重叠。整组内容在 81–719 px 的主显示区域内垂直居中；三条弧与全部文字均保留屏幕内边距，不贴边或溢出。中央圆环内自上而下显示无标签的白色档位数字 `6/13` 和主要读数 `3s PWR 245 W`；圆环下方从左到右显示 `CAD 88 rpm`、`SPD 28.6 km/h`、`HR 156 bpm`，保留草图的中轴结构。每条弧都有各自的分区及当前值标记。后拨档位 `6/13` 是序号，不显示飞轮齿数。

下方按草图排列两行辅助内容：

- 中下部从左到右：`AVG SPD 27.4 km/h`、`GRADE +4.8%`、`AVG HR 148 bpm`。
- 最底部从左到右：相对来风小箭头 `W`、`AVG PWR 198 W`、`NP 214 W`、指北针小箭头 `N`。

`W` 表示风来自骑手左前方；`N` 指向画面右上方。两个箭头的位置遵循本张草图，放在 Data Field 下方两侧。短标签取代草图中的单字母代号。让三个表盘和中央功率读数先被看到，再读速度与辅助指标；字号、材质、光效与装饰细节留给原型探索。

## 分区条语义

左侧踏频弧覆盖 51–110 rpm，每 5 rpm 一段，共 12 段；51–80 为白色，81–100 为绿色，101–110 为红色。左右两条包围弧都从下端的低值向上端的高值增长；三条弧的分区间隙具有相同的实际像素宽度。当前值标记统一为白色短线，沿各自圆弧的半径指向圆心，长度略超过指示条宽度；超出范围时停在最近的端点。中央功率弧从 0 到用户最高功率区的最大值，右侧心率弧从 0 到用户最大心率，分别采用 Karoo 用户功率和心率分区；各区在弧上等宽，区内按数值线性插值。功率、心率的颜色方向大体由绿、蓝、红到紫，具体色值暂不固定。三个当前标记分别指向 88 rpm、245 W 和 156 bpm。

这张图只展示一次骑行中的正常读数。后续原型可通过 JavaScript 改变数值和标记位置；缺失、断线等状态属于下一阶段。
