按情境检查

候选规则与取舍

线性：L(p) = clamp(p, 0, 400) / 4
聚焦：F(p) = p / 2　　　　　　　　（0 ≤ p ≤ 50）
　　　　　　　25 + (p − 50) × 5 / 7　 （50 < p ≤ 120）
　　　　　　　75 + (p − 120) × 5 / 56（120 < p ≤ 400）
S 曲线：H(p) = p^2.5 / (p^2.5 + 78^2.5)
　　　　 S(p) = 100 × H(clamp(p, 0, 400)) / H(400)

三种规则均先把有效输入限制在 0–400；无数据时不绘制指针。实际 % FTP 数字应原样显示，不能把刻度值当成功率百分比。
