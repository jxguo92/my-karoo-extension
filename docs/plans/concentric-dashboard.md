# Concentric Dashboard 开发计划

状态：功能与测试已实现；Android API 35 模拟器渲染验证通过，预览产物见 `demo/dashboard/concentric/validation/`。Karoo 真机验收待执行。

## 目标与已确认范围

新增图形 Data Field：显示名称 **Concentric Dashboard**，`typeId = concentric-dashboard`。以 [Concentric 原型](../../demo/dashboard/concentric/concentric.prototype.html) D/DL 和 [dashboard context](../../demo/dashboard/context.md) 为依据，D 对应夜间，DL 对应日间。

- 仅在 `gridSize == (60, 60)` 的整页位置显示；其他尺寸空白，不订阅数据、不请求天气。
- 固定公制，无点击动作、设置页或持久化设置。
- 根据 Android `uiMode` 自动切换主题，包括读数不变和预览场景。
- 不绘制原型顶部时钟、底部留白或方案切换按钮。
- 按 Q7 决定不显示天气来源标注，在字段文档中记录这一例外；不修改天气接口的通用契约。
- 术语见 [CONTEXT.md](../../CONTEXT.md)。旧 `prototype-description.md` 中的 Karoo 自定义功率区不作为新字段依据，Ladder Full 的专属决策不自动继承。

## 实现结构与数据接入

保持单 `app` 模块，在 `feature/datafield/concentricdashboard/` 内实现 SDK 适配、不可变状态、纯计算与格式化、天气策略、渲染和固定预览。复用现有 Karoo Flow、WeatherProvider 和 HTTP 路由，不引用其他字段的具体实现。

- `DataField` 只负责订阅、SDK 数据转换和视图生命周期；纯计算与状态归约不依赖 Android/SDK。
- `DataFieldRegistry.create` 增加构造天气服务及生命周期所需参数；Extension 拥有父 `SupervisorJob`，字段视图使用子任务。字段取消及 Extension 销毁均清理订阅、定时器和在途请求。
- 同步追加 XML、registry、字符串资源、字段文档与注册契约测试；保留现有字段顺序，新字段追加末尾。
- 本字段只提供图形视图，不额外订阅用于数值输出的中心 stream。

数据来源：

- 实时读数：`SMOOTHED_3S_AVERAGE_POWER`、`CADENCE`、`HEART_RATE`、`SPEED`、`ELEVATION_GRADE`。
- 辅助读数：`DISTANCE`、`AVERAGE_SPEED`、`AVERAGE_POWER`、`NORMALIZED_POWER`；平均心率类型为 `AVERAGE_HR`，字段为 `AVG_HR`。
- 档位读取后拨序号及总档数，显示 `6/13`；总档数缺失时显示 `6`，不转换齿数。
- `UserProfile` 提供 FTP、最大心率和静息心率；不读取用户自定义 zones。
- `LOCATION` 提供位置和车头朝向；朝向更新门限优先使用同一样本的 `LOC_SPEED`，缺失时使用最近有效 `SPEED`。

## 计算、状态与天气规则

### 分区与格式

- 功率采用 Coggan 七区，显示范围 41%–200% FTP；各区等弧长，区内线性插值。仅当前区整段点亮，指针表示实际位置。
- 心率采用 HRR 六区，当前数字按区着色，41% HRR 以下使用普通文字色。
- 分区边界使用连续上界比较，边界归较低区。参数无效时保留真实数字，功率弧无点亮或指针，心率使用普通文字色。
- 踏频按 50–110 计算连续填充；50 为空、51 开始填充、110 填满。填充颜色随当前踏频变化：≤80 白/日间深灰，81–100 绿，>100 红。
- 功率、心率使用整数；速度、距离、坡度使用一位小数，正坡度显示 `+`。指示位置钳制，数字不因仪表范围而截断；长数字缩小至可容纳，不省略数值。

### 缺失与骑行状态

- 缺失、非有限值及不可用状态独立降级为 `--`；对应弧保留静态轨道与刻度，隐藏填充和指针。
- 零功率、踏频、速度有效；心率须大于零，坡度允许负值。
- 暂停继续显示有效实时值。收到 `Idle` 后清空读数与方向显示、重置保存的朝向；直到 Recording/Paused 才恢复接收骑行读数。首次 RideState 尚未到达时不阻塞。
- 速度 ≥5 km/h 且朝向有效时更新朝向，否则保持最后有效值。本次骑行无有效朝向时隐藏风箭头与指北针；最终绘制角度四舍五入到 10°。

### 天气

- 复用和风配置及 Wi-Fi/手机 HTTP 路由；无配置或无有效位置时不请求。
- 首次有位置请求；距上次成功位置 >5 km 或成功后满30分钟刷新；失败后2分钟重试。同一视图最多一个请求在途。
- 使用可注入单调时钟计算刷新与过期；失败保留最近成功数据，超过60分钟后隐藏风箭头。
- 天气缓存和刷新独立于骑行状态；Idle 时隐藏天气显示，取消视图时终止请求。
- 相对风向、静风隐藏和四档风力严格沿用 context。日间采用加深配色；风力仅以颜色表达，不显示风速或来源文字。

## 渲染与主题

沿用项目现有 RemoteViews 路径：Android Canvas 绘制位图，由 ImageView 展示；不增加 Glance、Compose 或 DataStore 依赖。

- 设计坐标为 **480×638**，取原型中间字段区域，等比缩放并居中；实际位图尺寸不超过设计分辨率，非正 `viewSize` 使用设计尺寸。
- 忠实保留 D/DL 的280°同心弧、功率区径向渐隐、刻度、短指针、踏频轨道、中心与底部读数布局，以及日夜配色。中央使用系统 condensed 粗体，其他读数使用 sans-serif。
- 首帧立即显示占位或固定预览；之后每秒检查最新显示状态及 `uiMode`，仅变化时重新提交，全部刷新限制在1 Hz。
- `UI_MODE_NIGHT_YES` 使用 D，其余使用 DL；主题检查不依赖传感器发射事件。
- 每次提交独立 RemoteViews/位图，避免已提交图像被后续重绘修改；更新失败记录不含凭据的日志，保留后续刷新能力。
- 固定预览：245 W、88 rpm、156 bpm、28.6 km/h、6/13、42.7 km、+4.8%；平均速度27.4、平均心率148、平均功率198、标准化功率214；FTP200、最大/静息心率190/50。朝向315°、气象风向270°、持续风速4 m/s。两种主题共用此数据，预览不订阅传感器或天气。

## 测试与验收

先补纯计算、状态和注册测试，再连接 SDK 与渲染。

- **计算与状态**：分区边界、区内插值、越界钳制、参数无效、零值、非有限值、单项缺失、档位缺总数、暂停、Idle 清空与恢复。
- **方向与天气**：5 km/h 门限、低速保持、355°取整、顶风/顺风、静风及四档边界；5 km/30分钟/2分钟/60分钟阈值；失败保留缓存、请求串行及取消。
- **运行时**：非整页和预览零数据订阅；读数不变时主题仍更新；首次显示与后续1 Hz限制；退出后不再发图或请求。
- **注册契约**：XML 与 Kotlin ID 集合、顺序及唯一性一致，Extension ID 检查继续通过。
- **视觉检查**：固定日夜预览对照 D/DL，检查指针、颜色、字体、极端长读数及字段裁切；验证产物放入 `demo/`。
- **构建检查**：运行 `./gradlew testDebugUnitTest`，再运行 `./gradlew lint test assembleDebug`；若实际提供格式化任务则运行。已有和风 live test 在配置凭据时会真实联网。
- **Karoo 真机验收**：字段可发现和添加、整页尺寸、运行中日夜切换、断线/暂停/结束、Wi-Fi及手机网络天气、重复进出页面的订阅释放，以及位图传输稳定性。尤其确认 Karoo 页面主题变化是否传播至扩展进程的 `uiMode`；未实测项明确记录，不以 JVM 测试替代。
